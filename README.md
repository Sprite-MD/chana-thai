# Chana Thai

A commissioned website for Chana Thai, a local Thai restaurant in Inglewood, California. Built with vanilla HTML, CSS, and JavaScript — no frameworks — using the Fetch API to load menu data from an external JSON file.

## Features

- **Fixed navbar** with scroll-aware active section highlighting via IntersectionObserver
- **Hero section** with a full-screen background image
- **Dynamic menu** — category buttons load and render multi-column menu cards from JSON, with support for grouped categories, pricing variants, and add-on descriptions
- **3D carousel gallery** — CSS 3D transforms create a stacked perspective carousel with keyboard, click, and arrow navigation
- **Contact section** with location, hours, and a directions link
- **Responsive layout** with mobile breakpoints

## Stack

- HTML5, CSS3, JavaScript (ES6+)
- No external libraries or frameworks
- CSS custom properties for theming
- Fetch API for JSON data loading
